# How to use VDO Ninja 

## Prerequisites 

Two devices needed: 

1. the director (the computer that will use the video stream) 
2. a guest (a smartphone that will share one of its cameras) 

They need to be connected to the internet, ideally the same network. It is not known whether the app works on the school Wi-Fi or not, so a local network is preferred. 

## Steps 

### Set up the "director" 

1. Open https://vdo.ninja/ on the computer ([backup website](https://backup.vdo.ninja/)) 
2. Create a Room 
3. Room Name: 

```
photo_turntable_1_3_4_2
```

4. Optional: check "The guests can see the director, but not other guests' videos" 
5. Click on "Enter the room's Control Center in the director's role" 


### Set up the "guest" 

1. Open the following website: [Guest URL](https://vdo.ninja/?room=photo_turntable_1_3_4_2&broadcast&do) 

![QR CODE](attachments/Pasted%20image%2020251112212634.png)

2. Click on "Join Room with Camera" 
3. Allow the website to access the guest's microphone and camera 
4. Make sure the "Video Source" is set to "Back Camera" or similar 
5. Click on "START" 

### Finish set up 

Still on the director's page ([link](https://vdo.ninja/?director=photo_turntable_1_3_4_2)) 

1. "video settings": choose a higher resolution 
2. Click "copy solo view link" 
3. Access the copied URL it in a new browser tab 
4. `CTRL+RMB` on the video and select "Watch in Picture-in-Picture" (on Gecko web browsers, e.g. Mozilla Firefox) 
5. Full screen 
6. Done!
